# NAIS3 1.0.33

원본 NAIS3 v1.0.33 기반의 Windows x64 수정판입니다.

## 프롬프트 태그

- 태그 위에 마우스를 올리면 테마에 맞는 옅은 사각형 강조가 표시됩니다.
- 태그를 우클릭해 **태그 비활성화 / 태그 활성화**를 선택합니다. 마우스 오버 팝업은 사용하지 않습니다.
- 비활성 태그는 **회색 글자와 사각형 배경**으로 표시되며, 이미지 생성 요청과 토큰 계산에서 제외됩니다.
- 메뉴는 포인터가 벗어나도 유지되며 항목 선택, 바깥 클릭 또는 Esc로 닫습니다.
- 동일한 태그가 반복되어도 각각 따로 전환할 수 있습니다.
- 상태는 프롬프트 텍스트에 저장되어 프리셋과 함께 유지됩니다. 저장·복사되는 비활성 태그에는 내부 상태를 나타내는 결합 문자가 포함됩니다.
- 쉼표만 기준으로 태그를 구분하며, 조각 참조와 주석은 전환 대상에서 제외합니다.
- 줄 단위 `#` 주석 안의 쉼표와 가중치 구문은 태그 해석에 영향을 주지 않습니다. 비활성 태그를 제외한 뒤 남는 불필요한 쉼표도 정리합니다.
- 프래그먼트 편집창 안에서도 공통 우클릭 메뉴를 사용합니다. Esc는 메뉴만 닫고 입력창으로 포커스를 돌려줍니다.
- 태그 전환 시 커서·선택 영역과 스크롤 위치를 유지하며, Ctrl+Z / Ctrl+Y로 되돌리기와 다시 실행을 지원합니다.
- 선택한 글자와 검색 결과는 비활성 배경 위에서도 읽을 수 있으며, 마지막 줄바꿈이 있는 긴 프롬프트도 입력창과 표시 레이어의 스크롤을 맞춥니다.

가중치 내부의 태그가 모두 비활성화되면 가중치 구문도 회색으로 표시되고 생성 요청에서 제외됩니다. 하나라도 활성화되면 다시 적용됩니다.

## 이미지·라이브러리와 백업

- 이미지 우클릭 메뉴에서 이미지를 바이브 또는 캐릭터 레퍼런스로 추가하고 레퍼런스 패널에 드롭할 수 있습니다.
- ‘다시 생성’은 원본 이미지의 설정과 새 시드로 한 장을 예약하며 편집창 설정을 바꾸지 않습니다. I2I·인페인트 결과는 지원하지 않습니다.
- 메타데이터에서 바이브를 선택적으로 복원할 수 있으며 인코딩 모델을 모르면 직접 선택합니다.
- 프롬프트 프리셋 복제를 지원합니다.
- 비어 있는 작업 공간에서 데이터가 든 백업을 발견하면 복구를 안내합니다. 설정 → 저장에서 내부 백업을 복원하며 복원·가져오기 전 현재 DB를 보관합니다.
- .nais 및 씬 ZIP을 파일별로 스트리밍 저장하고 태그 자동완성 검색을 별도 워커에서 처리합니다.
- 무료 배경 제거는 최초 안내 동의 후 Hugging Face Space로 이미지를 전송합니다. 전송 전 생성 메타데이터를 제거합니다. BRIA RMBG 2.0 모델은 CC BY-NC 4.0 비상업 라이선스이며 서비스 이용 조건을 확인해야 합니다.

## 이미지 메뉴와 화면

- 이미지 우클릭 메뉴의 **시드만 복사**로 메타데이터의 시드 숫자만 복사할 수 있습니다. 시드 0도 지원합니다.
- 미리보기, 히스토리, 씬, 라이브러리, 확대 보기에서 공통 이미지 메뉴를 사용합니다.
- Windows QHD 화면의 정지 상태 글꼴 선명도를 위한 페이지 전환 처리를 적용합니다.
- 패널을 접거나 사이드 편집창을 열 때 정상 크기에서 옆으로 이동하며 축소합니다. 전환 중 다시 조작하면 현재 위치에서 이어지며, 정지 상태에서는 변환과 합성 힌트를 해제합니다.

## V5 정밀 레퍼런스

- V5 Curated, Full, Full Medium에서 지원합니다.
- 참조 타입: Character, Style, Character & Style, Costume.
- 강도 범위: **0~5**.
- Character와 Character & Style에는 **같은 의상 우선** 옵션을 제공합니다.
- V5의 충실도는 고정값을 사용하며 슬라이더를 표시하지 않습니다. V4.5용 저장값은 보존합니다.
- V5 참고 이미지는 종횡비에 가까운 약 1MP 규격으로 중앙 크롭하며, V4.5는 기존 여백 처리를 사용합니다.
- **V5 모델 인페인팅의 레퍼런스와 V5 바이브는 지원하지 않습니다.** Curated 인페인팅이 V4.5 모델로 전환되는 경우 실제 전송 모델의 레퍼런스 규칙을 따릅니다.
- 정밀 레퍼런스 비용은 공식 발표 기준 **생성 이미지 한 장당 참고 이미지 한 장마다 5 Anlas**이며, 비용 표시와 유료 생성 보호에 반영됩니다.


### 라이브러리와 적용 조건

| 구분 | 역할 |
| --- | --- |
| 일반 이미지 라이브러리 | 이미지와 스택 보관. 보관만으로 생성에 자동 적용되지 않음 |
| 레퍼런스 라이브러리 | 참고 이미지·타입·강도·충실도·활성화 상태·폴더 관리 |
| 바이브 라이브러리 | 참고 이미지·강도·정보 추출량·인코딩 캐시 관리 |

레퍼런스와 바이브는 검색, 폴더, 순서 변경, 복제, 다중 선택과 일괄 설정을 지원합니다. 폴더만 삭제하면 항목은 남습니다.

일반 생성과 사이드바 설정을 사용하는 씬 예약은 활성화된 항목을 사용합니다. 특정 **출연(Cast)** 으로 예약하면 출연의 항목 목록이 우선하며, 라이브러리 스위치가 꺼져 있어도 출연에 지정된 항목을 사용합니다. 출연 목록이 비어 있으면 레퍼런스 없이 생성합니다.

출연은 항목 ID를 기억하고 생성 직전에 현재 설정을 읽습니다. 예약 후 강도 등을 변경하면 나중에 실행되는 생성에 반영될 수 있습니다. 출연마다 다른 설정을 유지하려면 항목을 복제해 지정해 주세요. 이름·폴더·프롬프트 단어에 따른 자동 적용 조건식은 없습니다.

V4.5에서는 의상 전용 참조를 제외하고 의상 선호 타입을 기존 Character/Character & Style로 매핑합니다. 강도는 전송 시 최대 1로 제한하며 저장된 V5 강도는 보존합니다.

## 저장과 실행

참고 이미지는 앱 데이터의 refs 폴더에, 경로·썸네일·설정은 SQLite에 저장합니다. DB 스키마는 v20입니다. 종료 시 V5 토큰 계산 워커와 타이머·대기 요청을 정리합니다.
