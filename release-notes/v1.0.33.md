# NAIS3 1.0.33 — 태그 켜기·끄기 및 V5 레퍼런스

원본 **NAIS3 v1.0.32 기반 수정판**입니다. 기존 QHD 글꼴 선명도 개선과 이미지 우클릭 **‘시드만 복사’**를 유지하고, NovelAI V5의 정밀 레퍼런스 지원을 추가했습니다. 원본의 1.0.33 버전을 의미하지 않습니다.

## 프롬프트 태그 켜기·끄기

- 태그에 마우스를 올리면 옅은 사각형 강조와 마우스 위쪽의 켜기·끄기 버튼을 표시합니다.
- 끈 태그는 취소선으로 남고, 생성 요청과 토큰 계산에서 제외됩니다.
- 같은 태그가 반복되어도 각각 따로 전환할 수 있습니다. 끄기 상태는 프롬프트 텍스트에 결합 취소선 문자로 저장되어 프리셋과 함께 유지됩니다. 외부 편집기에 복사할 때도 해당 문자가 포함됩니다.
- 기본·네거티브·캐릭터 등 공통 프롬프트 편집기에 적용됩니다. 쉼표와 줄바꿈, 가중치 구분자를 기준으로 구분하며 조각 참조와 주석은 대상에서 제외합니다.

## 종료 처리 수정

V5 토큰 계산 워커가 종료 후 프로세스를 유지할 수 있는 경로를 수정했습니다. 메시지 리스너 등록 후 unref를 적용하고 종료 시 워커·타이머·대기 요청을 정리합니다. 실제 설치본의 종료·재실행 증상 재현 검증은 별도로 필요합니다.

## V5 레퍼런스 변경

- **V5 Curated, Full, Full Medium**에서 레퍼런스를 사용할 수 있습니다.
- V5 레퍼런스 강도를 **0~5**로 조절할 수 있습니다. 여러 항목의 일괄 설정에도 적용됩니다.
- 의상 참조(`Costume`)를 지원하고, Character 및 Character & Style에 **‘같은 의상 우선’** 스위치를 추가했습니다.
- 공식 V5 동작에 맞춰 충실도 슬라이더를 숨기고, 전송할 충실도를 고정합니다. 저장된 충실도는 V4.5에서 다시 사용할 수 있도록 보존합니다.
- V5 참고 이미지는 공식 웹앱과 같은 약 1메가픽셀 크기 목록에서 종횡비에 가까운 크기를 선택해 중앙을 잘라 맞춥니다. V4.5의 기존 여백 처리도 유지합니다.
- 레퍼런스 사용량을 비용 표시와 유료 생성 보호에 반영했습니다.
- V5 인페인팅에서는 레퍼런스를 전송하지 않고 비용에서도 제외합니다. V5 바이브는 계속 비활성화됩니다.

## 레퍼런스의 구조와 적용 조건

### 일반 라이브러리, 레퍼런스, 바이브

- **일반 이미지 라이브러리**는 이미지와 스택을 보관하는 공간입니다. 이미지를 보관하는 것만으로 생성에 자동 적용되지는 않습니다.
- **레퍼런스 라이브러리**는 참고 이미지마다 이름, 활성화 상태, 참조 타입, 강도, 충실도와 폴더 정보를 저장합니다.
- **바이브 라이브러리**는 별도로 관리되며 강도와 정보 추출량, 인코딩 캐시를 사용합니다. V5 레퍼런스 지원이 바이브 지원을 의미하지는 않습니다.
- 레퍼런스와 바이브는 이름 검색, 폴더 정리, 순서 변경, 복제와 다중 선택·일괄 설정을 지원합니다. 폴더만 삭제하면 안의 항목은 남습니다.

### 언제 적용되나요?

| 생성 방식 | 사용하는 레퍼런스 |
| --- | --- |
| 일반 생성 또는 사이드바 설정으로 씬 예약 | 활성화 스위치를 켠 항목 |
| 특정 출연(Cast)으로 씬 예약 | 해당 출연에 등록된 항목. 라이브러리 스위치 상태보다 출연 목록이 우선 |
| 출연의 레퍼런스 목록이 비어 있음 | 레퍼런스 없이 생성 |
| V5 인페인팅 | 레퍼런스 제외 |

레퍼런스 이름이나 폴더 이름에 따라 자동 적용하거나, 프롬프트의 특정 단어를 감지해 적용하는 조건식은 없습니다.

**출연은 이미지 복사본이나 설정 스냅샷이 아니라 항목 ID를 기억합니다.** 생성 직전에 해당 항목의 현재 이미지와 설정을 읽으므로, 예약 후 강도 등을 바꾸면 뒤에 실행되는 생성에 반영될 수 있습니다. 같은 이미지에 서로 다른 설정을 유지하려면 항목을 복제해 출연별로 지정해 주세요.

### 설정의 의미

- **Character**: 캐릭터의 외형을 참조합니다.
- **Style**: 그림의 스타일을 참조합니다.
- **Character & Style**: 캐릭터와 스타일을 함께 참조합니다.
- **Costume**: V5에서 의상을 참조합니다.
- **같은 의상 우선**: V5의 Character 또는 Character & Style에서 참고 이미지의 의상을 더 따르도록 지정합니다.
- **강도**: 참고 이미지를 얼마나 강하게 따를지 조절합니다. V5에서는 최대 5이며, 공식 안내는 스타일 반영이 약할 때 강도를 높여 보도록 설명합니다.
- **충실도**: V4.5에서만 조절합니다. V5에서는 공식 웹앱과 동일하게 고정값을 사용합니다.
- 기존 `Delta` 선택지는 유지하지만, 이번 작업에서 그 효과를 검증하지는 않았습니다.

V4.5로 바꾸면 의상 전용 레퍼런스는 제외하고, 새 의상 선호 타입은 기존 Character/Character & Style로 변환합니다. V5에서 저장한 1 초과 강도는 V4.5 전송 시 1로 제한하며 저장값 자체는 덮어쓰지 않습니다.

### 저장과 비용

데스크톱 앱은 참고 이미지를 앱 데이터의 `refs` 폴더로 복사하고, 경로·썸네일·설정은 SQLite에 저장합니다. 이번 변경에 DB 스키마 변경은 없으며 기존 레퍼런스·폴더·출연 구성을 유지합니다.

공식 발표 기준 정밀 레퍼런스는 **생성 이미지 한 장당, 레퍼런스 한 장마다 5 Anlas**가 추가됩니다. 여러 레퍼런스를 선택하면 각각 합산됩니다.

## 지원 범위와 검증

2026년 11월 24일 [공식 V5 정밀 레퍼런스 발표](https://journal.novelai.net/precise-reference-v5/)와 11월 25일의 공식 웹앱 코드를 확인해 구현했습니다. 발표에 명시된 대로 **V5 인페인팅의 레퍼런스 사용은 아직 지원하지 않습니다.**

로컬에서 관련 테스트 169개, 화면 타입검사와 변경 파일 린트를 통과했습니다. 릴리즈 빌드는 GitHub Actions에서 프로젝트에 지정된 의존성으로 전체 테스트·타입검사·Windows 패키징·패키지 실행 검사와 업데이트 파일의 체크섬 검증을 수행합니다.

**실제 NovelAI 서버에서 참고 이미지를 넣고 생성한 결과의 품질이나 성공 여부를 검증한 릴리즈는 아닙니다.** 실제 생성 테스트와 Anlas 소비는 수행하지 않았습니다.


## 설치 및 버전 안내

Windows x64 파일: **nais3-1.0.33-setup.exe**. 기존 v1.0.33 릴리즈의 수정 빌드이며 앱 버전과 태그는 유지합니다. **이미 1.0.33 또는 1.0.320을 사용 중이면 자동 업데이트 알림이 뜨지 않으므로 이 설치 파일을 다시 받아 수동 설치해 주세요.**

기존 태그의 소스는 유지하고, 이번 수정 빌드의 정확한 소스 커밋은 아래에 기록합니다. 실제 UI 마우스 동작과 NovelAI 서버 생성은 검증하지 않았습니다.

## 태그 팝업 위치 수정

태그 켜기·끄기 팝업을 마우스 좌표가 아닌 태그 바로 위에 고정했습니다. 같은 태그 안에서 포인터를 움직여도 위치를 유지하고, 닫기 타이머 중복을 정리했습니다. 화면 타입검사와 변경 파일 린트를 통과했습니다.

## 비활성 태그 표시 및 팝업 수정

버튼을 ‘태그 비활성화 / 태그 활성화’로 변경했습니다. 팝업 위에 마우스가 있는 동안 닫기 타이머가 팝업을 숨기지 않습니다. 비활성 태그는 취소선 대신 회색 글자와 사각형 배경으로 표시하며 밝은·어두운 테마별 색상을 적용했습니다. 관련 테스트 31개, 화면 타입검사와 린트를 통과했습니다. 실제 화면 검증은 수행하지 않았습니다.
