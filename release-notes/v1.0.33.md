# NAIS3 1.0.33 — 시드만 복사 추가

원본 v1.0.32 기반의 umirr Fork 업데이트입니다.

## 추가 기능

- 이미지 우클릭 메뉴의 ‘메타데이터 보기’ 아래에 **‘시드만 복사’**를 추가했습니다. 메인 미리보기, 히스토리, 씬 이미지, 라이브러리, 확대 보기에서 사용할 수 있습니다.
- 이미지 메타데이터에서 시드를 읽어 숫자만 클립보드에 복사합니다. 값이 0인 시드도 지원합니다.
- 시드가 없거나 메타데이터 읽기·클립보드 접근에 실패하면 안내 메시지를 표시합니다.
- 한국어·영어·간체 중국어 메뉴와 안내 문구를 제공합니다.

포크의 QHD 글꼴 선명도 개선과 원본 v1.0.32의 변경 사항을 포함합니다.

## 설치

Windows x64 설치 파일 `nais3-1.0.33-setup.exe`를 실행하거나 기존 포크 앱에서 업데이트할 수 있습니다. 수동 설치할 때는 기존 앱을 종료해 주세요. DB 스키마는 v20이며 설치 파일은 코드 서명되지 않았습니다.

## 검증

시드 복사·누락·오류 처리와 번역 관련 로컬 테스트 42개, 렌더러 타입 검사, 변경 파일 린트를 통과했습니다. 릴리즈 워크플로에서 전체 테스트, 타입 검사, Windows 패키징, 패키지 내부 실행 검사, 설치 파일 및 업데이트 메타데이터 체크섬을 검증합니다.
