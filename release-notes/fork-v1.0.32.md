# NAIS3 1.0.32 — Windows 포크 업데이트

[원본 v1.0.32](https://github.com/sunanakgo/NAIS3/releases/tag/v1.0.32)와 [원본 v1.0.31](https://github.com/sunanakgo/NAIS3/releases/tag/v1.0.31)의 변경 사항을 포함합니다.

- 화면 배율 단축키가 개선됐으며, 설정 → 모양에서 배율을 조정하거나 100%로 되돌릴 수 있습니다.
- Anlas가 드는 요청을 차단하거나 일일 사용량에 한도를 설정할 수 있습니다.
- 키체인이 잠겨 있을 때 계정 토큰을 보존합니다. 삭제한 씬의 대기 작업을 취소하고, 백업을 복원할 때 이미지와 씬의 연결을 유지합니다.
- Electron 45를 적용하고, 파일 대화상자가 마지막 폴더를 기억하며, Windows 설치 파일에서 불필요한 파일을 제외했습니다.
- 포크 v1.0.31에서 사용자 확인을 받은 QHD 글꼴 선명도 개선을 유지했습니다. 원본에 추가된 좌우 패널 전환에도 같은 처리를 적용했습니다. 이번 버전의 실제 QHD 화면은 별도로 비교하지 않았습니다.

포크 v1.0.31 사용자는 앱에서 업데이트하거나 Windows x64 설치 파일을 실행할 수 있습니다. DB 스키마는 v20입니다. 설치 파일은 코드 서명되지 않았습니다.
