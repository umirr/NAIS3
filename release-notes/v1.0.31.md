# NAIS3 1.0.31 — Windows 글꼴 렌더링 개선 (umirr Fork)

이 릴리즈는 [sunanakgo/NAIS3](https://github.com/sunanakgo/NAIS3) v1.0.30 기반의 개인 Fork 빌드입니다.

## 개선 사항

- 작업 화면과 별도 페이지의 `will-change`를 페이지 전환 중에만 적용하고, 전환 후 해제합니다.
- 작업 화면 복귀 및 페이지 열기 완료 후 불필요한 이동·축소 `transform`을 제거합니다.
- Windows에서 정지 상태의 작은 글자에 서브픽셀 렌더링을 방해할 수 있는 조건을 줄였습니다.
- 기존 전환 효과, 작업 상태, 포커스 이동은 유지하며, 빠르게 닫고 다시 여는 동작의 회귀 테스트를 추가했습니다.
- 배포 및 업데이트 저장소를 `umirr/NAIS3`로 설정했습니다.

## 다운로드 및 설치

- Windows x64 설치 파일: `nais3-1.0.31-setup.exe`
- 기존 NAIS3를 종료한 뒤 설치 파일을 실행하세요. 기존 앱과 같은 앱 ID 및 기본 설치 경로를 사용하므로 기존 설치를 업데이트합니다.
- 이 빌드는 코드 서명되지 않았습니다.
- GPL-3.0 소스는 이 릴리즈의 태그와 GitHub의 Source code 다운로드에서 확인할 수 있습니다.

## 검증 범위

릴리즈 워크플로는 전체 테스트(SQLite 통합 테스트 포함), 타입 검사, Windows 패키징, 패키지 내부 SQLite·sharp 실행 검사, 설치 파일 및 업데이트 메타데이터의 크기·SHA-512 검증을 통과한 경우에만 게시합니다.

실제 QHD 디스플레이에서 Windows 배율 100%·125%·150%별 글자 선명도, 애니메이션 성능, 설치·업그레이드의 GUI 동작은 아직 수동 검증하지 않았습니다.
